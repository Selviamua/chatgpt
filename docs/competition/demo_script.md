# 5分钟路演 Demo 讲稿（可直接使用）

## 0:00-0:40 痛点
“在生物医药项目里，临床/伦理/数据合规文档通常要人工审查，效率低且容易漏项。我们做了一个生物医药合规文档 Agent，先做自动预审，再交给专家复核。”

## 0:40-1:30 方案
“系统接收文档后，会依次完成规则扫描、风险评分、整改建议生成，最后输出结构化审查报告。当前MVP覆盖5条高价值规则：伦理审批、知情同意、不良事件、数据隐私、版本追溯。”

## 1:30-3:40 现场演示
1. 运行命令：
   - `python main.py samples/clinical_protocol_sample.txt --output deliverables/compliance_report.md`
2. 展示终端输出风险分；
3. 打开报告，展示每条规则的证据与建议；
4. 切换到缺失条款的文档（可临时删掉关键段落）演示风险上升。

## 3:40-4:30 技术亮点
- 可解释：每条结论都有证据与建议；
- 可扩展：规则引擎可平滑演进到语义检索和法规知识库；
- 可落地：离线可跑，便于接入企业内网环境。

## 4:30-5:00 收尾
“我们把 Agent 定位为‘合规预审助手’，不是替代专家，而是显著提升初审效率和一致性。下一步会接入法规知识库和真实业务数据集，提升准确率与泛化能力。”
