# 《科技入侵现代》科技与 AI 资料包

本目录保存小说原文、分析脚本和最终面向上传的整合资料包。

## 最终上传文件

- `output/NOVEL_TECH_AI_DOSSIER.md`：主资料包，建议必传。
- `output/EVIDENCE_QUOTES_BANK.md`：原文证据摘录库，可选上传。

## 目录

- `raw/科技入侵现代.txt`：小说原文。
- `scripts/build_dossier.py`：章节切分、候选证据提取和文档生成脚本。
- `output/`：最终整合文档。

## 生成方式

```bash
python3 novel-ai-wiki/scripts/build_dossier.py
```
